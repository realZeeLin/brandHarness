另外人工验证：`dsh plugin --profile web add …` 后 web profile 由 `@deepseek-ai/dsh-base` → `@deepseek-ai/dsh-web-app` → `dsh-plugin-brand-insight` 组成，`dsh web` 正常启动（首次进入需登录 DeepSeek 账号或添加 API Key）。

## 6. 已知限制

- 离线模式的叙述文字由模板生成（数字来自工具）；自然语言的灵活应答需在线模型或 DeepSeek Harness。
- 观点与情感抽取为规则词典 + 否定窗口，个别评论会被误判；证据按「净负面程度」排序以减小影响，口径说明随结果返回。
- 真实 DeepSeek 模型调用未在本环境测试（无密钥）；在线循环用模拟 API 做了单元测试，dsh 链路用脚本模型做了端到端测试。
- DeepSeek Harness 为开发者预览版，后续版本可能有不兼容变更；组合包已声明 `engines.dsh` 范围。
