# 活动全周期复盘

## 四问
1. 品牌说了什么（标题 / 素材表达）
2. 用户复述了什么（评价 / 社媒自然 UGC，去掉促销话术）
3. 渠道怎么走（区间口径，不估算金额、不推同比）
4. 增量是多少（需投放花费与反事实基线；未接入写「未知」）
