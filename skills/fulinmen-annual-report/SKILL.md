# 食用油年度 AI 报告

## 步骤
1. 锁定数据源与口径门禁
2. 分派：洞察分析师（诊断）、产品机会官（动作包）、品牌追踪官（品牌）、活动复盘官（渠道）、GEO 优化官（AI 答案）
3. 逐章输出「信号 / 发现 / 洞察 / 建议」四层
4. 动作包写明负责人、周期、验收
5. 自检：数字与工具返回逐一核对；提交分析师审核

## 约束
- 没有依据写「未知」；区间数据不取端点、不推同比
- 换品类只换业务地图与字典
